# AI Usage Report

## AI Tools Used

The following AI tools were used during the development of this project:

- GitHub Copilot
- ChatGPT (OpenAI)

---

## Purpose of AI Usage

### GitHub Copilot

GitHub Copilot was primarily used for:

- Code completion
- Generating boilerplate code
- Suggesting React component structures
- Assisting with FastAPI endpoint implementation
- Writing repetitive CRUD operations
- Improving code productivity

---

### ChatGPT

ChatGPT was used for:

- Understanding FastAPI concepts and best practices
- Debugging frontend and backend issues
- Explaining errors and suggesting fixes
- Assistance with CI/CD pipeline setup
- Guidance for Docker and deployment
- Help with GitHub Actions / CI configuration
- Improving project documentation
- Code review and optimization suggestions

---

## Human Contribution

All project requirements, architecture, implementation decisions, testing, debugging, and integration were completed and verified manually.

AI tools were used only as development assistants to improve productivity and understand concepts. Final implementation decisions and code integration were performed by the developer.

---

| AI Tool        | Purpose                                                                                |

| GitHub Copilot | Code completion, boilerplate generation, and coding assistance                         |
